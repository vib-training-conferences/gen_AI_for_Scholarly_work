- Open your browser and surf to [Copilot](https://copilot.cloud.microsoft) or [Claude](https://claude.ai) or your AI product of choice.

- Zoom in to a specific question and focus on generating keywords, search strings, with subsequent topic scoping:

## Steps to keep in mind

```
1. Define AI Persona 
You are an expert scientific literature search specialist in bioinformatics, proteomics, and computational biology.

2. Give Context 
I want to you identify keywords that can be used to build Google Scholar search strings on this topic: proteomics-based complex discovery methods in pertubated states in disease

3. Clear Verbs and Structure
Group keywords into: 
- Biological concepts 
- Experimental and computational methods 
- Resources, tools, and data sources 
- Include important synonyms and related terms. 
- Create three Google Scholar search strings:
  - Specific 
  - Balanced 
  - Broad
  
4. Define Output (Style)
Use the pipe "|" symbol for OR and refrain from writing out AND while keeping an syntactically valid search string.

Output format: 
A. Main Keywords - … 
B. Related Terms and Synonyms | Concept | Alternative Terms | 
C. Search String 1 (Specific) 
D. Search String 2 (Balanced) 
E. Search String 3 (Broad) 
```
## Activity

1. Use Copilot to generate keywords and generate a Google Scholar search string

2. Iteration: Ask for different keywords

3. Apply the string and explore what comes out of Google Scholar

4. Iteration: identify topics for further exploration

P.S.: Evaluate the results in each step.
